# Выгрузка и аналитика — черновик scope

**Статус:** черновик для согласования / план работ.  
**Дата:** 2026-07-23 (обновлено: приоритет — выгрузка, аналитика отложена)  
**Контекст мини-ТЗ:** *«инструменты аналитики (прогнозирование свойств, статистические расчёты, генерация отчётов по сканам/образцам/материалам)»*.

**Решение по приоритету:** сначала **выгрузка данных в таблицу (XLSX)** — удобно отправить коллеге или доработать вне системы. Графики, статистика на дашборде и прогнозирование — **позже**, когда будет более чёткое ТЗ.

---

## 1. Что уже есть в продукте

| Источник | Полезно для выгрузки | Ограничение |
|----------|----------------------|-------------|
| Материалы (ORM) | код, название, справочники, тип структуры, теги, источник импорта, даты | активное пространство (+ общие по правилам видимости) |
| Свойства материалов / образцов | колонки по свойствам справочника | EAV: `value` + `value_kind` + `value_b` |
| Образцы | код, материал, тип объекта, даты | — |
| Сканы (метаданные) | метод, образец, название, дата файла | **содержимое HDF5 не выгружаем** |
| Поля типов структур | колонки SQL-строки по типу | схемы типов разные |
| Импорт XLSX/CSV | зеркальный сценарий «завезли → вывезли» | идеальный round-trip не обязателен в v1 |
| Дашборд | слот «Аналитика» (заглушка) | аналитика UI отложена |

**Нет сейчас:** кнопки экспорта списков, ML/прогноза, разбора HDF5.

## 2. Export v1 — следующий срез (в работе / к реализации)

**Пользователь:** менеджер / оператор в активном workspace.  
**Сценарий:** «отфильтровал список → выгрузил таблицу → отправил кому-то / открыл в Excel».

### В scope Export v1 — согласовано и в реализации

1. **Кнопка «Выгрузить в Excel»** на списке: нужны отмеченные строки одного **типа структуры**; иначе модалка.
2. **POST** выбранных `ids` (вкладка Пространство / Общие учитывается); сервер отклоняет смесь типов / без типа.
3. **Лист «Материалы»:** код, название; непустые метаданные; **все поля типа структуры**; свойства справочника у выбранных; **без** тегов / «Создал» / даты.
4. **Формат:** `.xlsx` (`apps/materials/export.py`), удобная таблица, не round-trip импорта.
5. **Права:** всем, кто видит список.

### Позже (не v1)

- Листы образцы / сканы; CSV; приближение колонок к формату импорта.

### Вне scope Export v1

| Тема | Когда |
|------|--------|
| Идеальный round-trip «выгрузка = импорт без правок» | Export v2 / вместе с доработкой импорта |
| PDF-отчёты с шапкой и подписями | отдельное ТЗ |
| Выгрузка массивов из HDF5 | только после спецификации скана |
| Страница «Аналитика», графики, mean/median по свойствам | **отложено** (см. §3) |
| Прогнозирование свойств | отложено, нужно отдельное ТЗ |

## 3. Аналитика — отложено

Мини-ТЗ по аналитике **не отменяем**, но **не берём в ближайший срез**.

Когда вернёмся (после Export v1 и уточнения ТЗ), кандидаты:

| Позже | Содержание |
|-------|------------|
| **Analytics UI** | страница / слот на дашборде: динамика созданий, срезы по справочникам, статистика по одному свойству |
| **Отчёты 2.0** | «паспорт материала», период, PDF |
| **Статистика по структурам** | срезы по полям выбранного `StructureType` |
| **Прогноз (каталог)** | после выбора целевого свойства и признаков |
| **Метрики по скану** | после контракта HDF5 + фоновые задачи |

Заглушку на дашборде можно пока не трогать или заменить текстом вроде: «Сводка и графики — в планах; данные можно выгрузить из списка материалов».

## 4. Технический контур Export v1 (ориентир)

- Логика в `apps/materials/` (view + сервис сборки строк), без обязательного `apps/analytics`.
- Queryset: тот же visibility + фильтры, что `material_list`.
- Свойства: join `MaterialProperty` → `Property`; числа — через `property_number_value` для единообразного текста в ячейке.
- Ответ: `HttpResponse` / `FileResponse` с `Content-Disposition: attachment`.
- Лимит строк: на первом шаге разумный cap (например несколько тысяч) + сообщение, если обрезали; при росте — фоновая задача.
- Тесты: выгрузка пустого списка, нескольких материалов, с фильтром, проверка workspace isolation.

## 5. Согласованные решения (2026-07-23)

| Вопрос | Решение |
|--------|---------|
| Объём v1 | **Только материалы** (образцы/сканы — позже) |
| Свойства | **Все свойства**, встречающиеся в выгрузке (wide: колонка на свойство) |
| Права | **Всем**, кто видит список материалов |
| Цель файла | Сознательно **удобная таблица** для передачи коллегам, не идеальный round-trip с импортом |

---

## 6. Краткая формулировка для заказчика

> Сейчас рациональнее сделать **выгрузку каталога в Excel** (с учётом фильтров списка) — чтобы можно было отправить данные коллегам.  
> Полноценная **аналитика** (графики, статистика, прогноз) и разбор **HDF5** требуют более детального ТЗ и откладываются на следующие этапы. Выгрузка частично закрывает пункт мини-ТЗ про «генерацию отчётов» в табличном виде.
