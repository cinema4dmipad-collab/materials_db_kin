Справка по работе с базой

Эта страница описывает, как устроен сайт, в каком порядке вводить данные и на что обратить внимание. Разделы ниже соответствуют пунктам верхнего меню.

Общая схема данных

Данные связаны между собой так:

  1. Справочник свойств — названия и единицы измерения (плотность, модуль упругости и т.п.).
  2. Материал — карточка композита или заготовки с кодом, типом структуры и значениями свойств.
  3. Образец — конкретная деталь или пластина из материала; свойства можно уточнить для образца.
  4. Сканы и файлы — прикрепляются к образцу (ультразвуковые HDF5, фото, отчёты).

Рекомендуемый порядок: сначала завести нужные свойства в справочнике, затем материал, потом образцы и измерения. Данные хранятся в рабочих пространствах — переключатель в верхней панели.

Интерфейс

Рабочее пространство

В верхней панели слева от имени пользователя — переключатель рабочего пространства. Списки материалов, образцов, сканов, тегов и таблица материалов типа структуры показывают данные активного пространства. Если у вас несколько пространств, выберите нужное перед работой.

Дашборд

На главной — дата, блок Требуют внимания (в т.ч. Продолжить импорт при незавершённом мастере и Импорт к разбору для материалов со статусом «на проверке»), сводка по пространству и ленты недавних записей.

Профиль пользователя

Имя пользователя в правой части шапки — кнопка перехода в профиль: логин, контактные данные, дата регистрации и список пространств с вашими ролями. В профиле также можно создать токен API (KeenetiX и HTTP API v1): секрет показывается один раз — скопируйте его в окне (закрыть без копирования нельзя); если секрет потерян, нажмите «Обновить секрет».

Колонка «Создал»

Во многих списках (материалы, образцы, теги, свойства, сканы) отображается, кто создал запись. Имя автора оформлено как кнопка-метка: нажмите на неё, чтобы отфильтровать список по этому пользователю.

Закладки

В шапке кнопка В закладки сохраняет текущую страницу (название, иконка и цвет на выбор). Если страница уже в закладках, кнопка показывает В закладках (повторно добавить нельзя). На пунктах бокового меню (разделы приложения, настройки пространства, администрирование) кнопки закладок нет — они и так в меню. Список закладок — в боковой панели и на странице закладок.

Справочник свойств

Открыть раздел

Раздел Свойства в меню — отдельный пункт верхней навигации; это общий каталог параметров, которые потом выбираются в материалах, образцах и типах структур.

  • Название — как свойство видно в интерфейсе (можно на русском).
  • Код свойства — заполняется автоматически из названия; при необходимости можно поправить вручную.
  • Единица измерения — необязательно (МПа, г/см³, % и т.д.).
  • Тип данных — число, строка, да/нет, дата, ссылка на материал или выбор из списка.
  • Знаков после запятой — для числовых свойств; влияет на ввод и отображение значений.
  • Группа — для удобной группировки в списках (группы создаются в админке).
Добавлять, изменять и удалять свойства в справочнике может только системный администратор. Остальные пользователи просматривают каталог и выбирают свойства в формах материалов и образцов. Администратор может удалять сразу несколько свойств через кнопку Выбрать в списке.

Один раз добавленное свойство можно использовать во многих материалах и образцах.

Справочники материалов

Открыть раздел

Раздел Справочники в меню — списки значений для полей карточки материала: производители, доступность и технологии. Они общие для всей системы (не зависят от пространства) и используются в фильтрах списка и при импорте.

Просмотр доступен ролям с правом на свойства; создавать и менять записи может только системный администратор. В списках справочников администратор может группово удалять записи кнопкой Выбрать.

Материалы

Открыть раздел

Вкладки «Пространство» и «Общие»

Список материалов разделён на две вкладки:

  • Пространство — материалы, созданные в текущем рабочем пространстве. Здесь доступно создание новых материалов. Кнопка Выбрать включает режим множественного выбора для группового удаления (только свои материалы, которые можно удалить). Подтверждение удаления (одиночного и группового) показывается в диалоге на этой же странице.
  • Общие — опубликованные материалы, доступные в этом пространстве (с общей видимостью или из других пространств). Чужие материалы можно просматривать, но не редактировать.
  • Выгрузить в Excel — сначала «Выбрать», отметьте материалы одного типа структуры, затем выгрузку. В файл: код, название, заполненные метаданные (без тегов), все поля этого типа структуры и свойства справочника у выбранных строк. Разные типы в одном файле нельзя (пустые колонки метаданных не добавляются; удобная таблица, не формат обратного импорта).

Основные поля

  • Код — уникальный идентификатор (например, CMP-CFRP-T700-EP).
  • Название — понятное описание материала.
  • Справочные свойства (Производитель, доступность, технология) — в форме материала добавляются кнопкой «Добавить», а не висят пустыми полями. Значения берутся из общих справочников системы (раздел «Справочники», правка — администраторам). В списке материалов по ним можно фильтровать.
  • Тип структуры — определяет набор параметров конструкции (сэндвич, монолит и т.п.). Тип должен иметь созданную SQL-таблицу; после выбора появятся дополнительные поля, при смене типа страница перезагрузится.
  • Теги — необязательные метки для поиска. На карточках материала, образца и скана (в своём пространстве) теги можно менять сразу, без полной формы; также в формах создания/редактирования (см. раздел «Теги»).

Импорт из файла

Пункт Импорт в боковом меню «Разделы» открывает гибкий мастер CSV/XLSX.

  • На шаге «Лист и структура» выберите тип структуры (обязательно, через ту же модалку выбора, что в форме материала) — параметры из Excel попадут в «Из параметров структуры» на карточке материала. Номера строк заголовков/групп показываются только если в файле двухуровневая шапка (как в «Сводной»); для обычной таблицы с одной строкой заголовков они скрыты. На этом же шаге есть схема первых строк файла — где группы, заголовки и данные.
  • Опция «Создавать неизвестные значения справочников» (шаг «Лист и структура») — если в файле производитель / доступность / технология отсутствуют в справочнике, они создаются вместе с записью материалов (при отмене или ошибке импорта лишние записи в справочнике не остаются). В отчёте проверки видно список новых значений; совпадения по имени или коду (без учёта регистра и лишних знаков) не создают дубликаты.
  • Сопоставьте поля записи с колонками файла в конструкторе: слева строки полей (структура + обязательные), справа каталог колонок Excel — клик или перетаскивание в слот «Колонка файла» (между полями — обмен, в каталог — сброс). Дополнительные свойства добавьте кнопкой «Добавить свойство» в одноимённом блоке; производителя, теги и другие поля материала — через «Поле материала» в блоке «Справочники». Общие теги на все материалы партии задаются блоком «Теги для всех материалов» под конструктором (можно выбрать существующий или ввести новый; цвет нового — по умолчанию, меняется палитрой на чипе; теги сохраняются в шаблоне). Здесь же на шаге «Запись» — предупреждение о дубликатах по названию: если материал с таким названием уже есть в пространстве, можно не записывать эти строки, добавить префикс или постфикс и создать как новые. Перезапись существующих материалов из импорта запрещена. Колонка «Марка» не подставляется автоматически — добавьте поле «Теги» через «Поле материала» (обычно уходит в тег марка::…). Обязательно назначьте колонку на поле Название (лучше «Наименование», а не «Марка»: марка часто пустая у части строк). Строки с пустым названием пропускаются и не блокируют импорт остальных. «Тип поля» — авто / текст / число / да·нет / дата.
  • Объединённые ячейки Excel (одно значение на несколько строк/столбцов) при чтении «разворачиваются»: то же значение попадает в каждую строку объединения.
  • После сопоставления колонок выберите режим записи: Вперёд (полный черновик всех строк, затем запись) или построчно (сразу к первой строке с подтверждением; удобно для «грязных» файлов). На каждом шаге есть кнопки Назад / Вперёд.
  • В числовых ячейках допускается хвост единиц или ширина полоски (12,5 мм, 4050/ 50мм) — в базу попадает число, единицы отбрасываются (единица уже задана полем структуры/свойства). Записи вида 0,27+0,035 читаются как значение с ± погрешностью.
  • В пакетном режиме система строит черновик. Если числовое значение не удалось разобрать (например 160(+10)/100(±10) или дата вместо числа), запись останавливается: на шаге «Запись» показывается таблица вроде Excel — проблемные ячейки жёлтые; клик открывает форму правки снизу (или можно игнорировать — поля останутся пустыми), затем импорт применяется сразу. Любые ячейки можно править по клику; изменённые вручную подсвечиваются синим, исправленные предупреждения — зелёным. Кнопки «Игнорировать все и записать» и «Записать» продублированы под таблицами. Если при «Записать» одно поле с ошибкой, уже исправленные значения сохраняются — жёлтым остаётся только проблемное.
  • При ошибках валидации запись запрещена — вернитесь к сопоставлению, поправьте маппинг и снова соберите черновик.
  • Маппинг можно сохранить шаблоном и применить на шаге сопоставления колонок (вместе с типом структуры и общими тегами партии).
  • Любую открытую страницу можно закрепить кнопкой В закладки в шапке (см. раздел Интерфейс). Путь к материалам структуры: боковая панель → Структуры → карточка типа → таблица материалов.
  • Новые материалы из импорта получают тег статус::на проверке и попадают в колонку На проверке на странице Проверка импорта. Перенос в колонку Учрежден ставит статус::учрежден. На дашборде в «Требуют внимания» — пункт Импорт к разбору.
  • На стенде с IMPORT_BATCH_UNDO=true (или при локальном DEBUG) после импорта доступна кнопка удаления результата последнего импорта в этом браузере/сессии.
  • На шаге загрузки можно скачать пример большой таблицы Excel/CSV для тренировки импорта.

Свойства материала

В блоке «Свойства» нажмите Добавить и выберите параметр из справочника в диалоге выбора. Название и единица измерения подставляются автоматически — вводите только значение. Для числовых свойств можно указать точное значение, диапазон (от–до) или значение с ± погрешностью. Строки можно удалять кнопкой ✖.

Слои композита

Если для выбранного типа структуры разрешены слои, появится таблица укладки: материал слоя, угол армирования и толщина, мм. Над таблицей — панель действий: добавить строку, копировать, удалить, переместить вверх/вниз. Порядок слоёв можно менять перетаскиванием за маркер ⋮⋮ слева от строки. На карточке материала отображается схема укладки и суммарная толщина.

Выбор материала в формах

В форме образца, в слоях композита и в полях типа «материал» у структуры открывается диалог выбора материала. В нём те же вкладки Пространство и Общие, поиск по коду и типу структуры, группировка по типу. На вкладке «Пространство» есть кнопка «Создать» новый материал.

Карточка материала

На странице просмотра — свойства, слои, параметры структуры, образцы, вложения. Отсюда же можно перейти к редактированию или создать образец из этого материала. В списке материалов клик по метке типа структуры или по имени в колонке «Создал» включает соответствующий фильтр. Материалы, загруженные из файла, можно отфильтровать по источнику импорта (по имени загруженного файла).

Типы структур

Открыть раздел

Тип структуры задаёт, какие дополнительные поля появятся у материала (толщина, тип обшивки, ссылка на другой материал и т.д.). Для каждого типа в базе данных создаётся отдельная SQL-таблица с записями параметров конструкции.

Создание типа

  • Название — на русском; из него автоматически формируется код типа (транслит + snake_case).
  • Имя SQL-таблицы — можно задать вручную или оставить пустым: тогда имя построится автоматически из названия (например, structures_sendvichnaya_panel).
  • Цвет в списке материалов — цвет метки типа (#RRGGBB): пресеты или свой цвет; меняется и после создания таблицы.
  • Разрешить слои — включает таблицу слоёв композита в форме материала.
  • Свойства структуры — колонки SQL-таблицы; можно добавить из справочника свойств или создать поле вручную. Для десятичных полей — точность и режим значения (точное / диапазон / ±), как у числовых свойств материала.

Имя SQL-таблицы — правила

Имя проверяется перед сохранением и созданием таблицы. Допустимы только безопасные идентификаторы:

  • обязательный префикс structures_;
  • после префикса — латиница, цифры и подчёркивание (snake_case), имя начинается с буквы;
  • не длиннее 100 символов, без пробелов и спецсимволов;
  • не должно совпадать с зарезервированными SQL-словами и именами служебных колонок;
  • уникально среди всех типов структур.

Если имя не проходит проверку, форма покажет ошибку — таблица не будет создана, пока имя не исправлено.

Создание таблицы в базе данных

После сохранения нового типа система предложит создать SQL-таблицу в модальном окне. Можно согласиться сразу или нажать «Позже» и вернуться к этому на странице управления типом. При каждом открытии страницы типа без созданной таблицы напоминание появится снова.

На странице управления в блоке «SQL-таблица в базе данных» можно проверить или изменить имя таблицы и нажать Создать. В таблицу попадут служебные колонки (id, created_at, updated_at, created_by) и колонки из списка свойств типа.

После создания SQL-таблицы существующие поля нельзя менять или удалять, но можно добавлять новые колонки. Имя SQL-таблицы фиксируется. Материалы можно привязать к типу только после создания таблицы.

Список типов и материалы

  • В списке типов клик по названию или карточке открывает материалы этой структуры; шестерёнка — только управление типом (поля, SQL-таблица).
  • На странице записей — таблица материалов текущего рабочего пространства (общие материалы из других пространств сюда не попадают): название, код и только поля этой структуры (без доп. свойств справочника; заголовки полей с единицами не обрезаются). Если колонок много — горизонтальный скролл; название и код остаются слева. Поиск работает как у материалов (код, название, описание, теги, справочники и т.д.), даже если эти признаки в таблице не показаны.
  • Кнопка Создать запись добавляет строку параметров в SQL-таблицу; с карточки записи по-прежнему доступно Развернуть для связанных материалов.
  • Цвет типа можно менять на странице управления даже после создания таблицы.
  • Настройка полей и SQL-таблиц — задача администратора базы; при сомнениях обратитесь к ответственному за систему.

Образцы

Открыть раздел

Образец — конкретная единица (пластина, деталь, контрольный элемент), изготовленная из материала.

В списке образцов кнопка Выбрать включает режим множественного выбора для группового удаления (вместе со сканами и вложениями).

Поля образца

  • Код и название — уникальный код и краткое описание.
  • Материал — обязательная связь с карточкой материала. Нажмите «Выбрать» или поле с названием — откроется диалог с вкладками «Пространство» и «Общие» (см. раздел «Материалы»).
  • Тип объекта — испытательный, контрольный, изделие и др. В списке образцов тип можно выбрать кликом по цветной метке — подставится фильтр.

Свойства образца

При выборе материала свойства подставляются автоматически из его карточки. Значения можно изменить — они сохранятся только для этого образца. Числовые свойства поддерживают точное значение, диапазон и ± погрешность — так же, как у материала.

Если добавить свойство, которого нет у материала, система покажет предупреждение (жёлтая подсказка в форме и сообщение после сохранения). Это не ошибка — образец может иметь дополнительные параметры.

Сканы HDF5 и произвольные файлы прикрепляются на вкладках «Сканы» и «Файлы» уже после создания образца.

На вкладке «Файлы» образца можно прикрепить фото, PDF и другие документы с названием и описанием.

Прогресс загрузки и скачивания

При загрузке файлов через форму и при скачивании вложений внизу экрана показывается индикатор прогресса. Дождитесь завершения передачи, прежде чем закрывать вкладку.

Поиск и фильтры

На страницах списков (материалы, образцы, сканы, свойства и др.) используется единая панель фильтров:

  • Где искать — отметьте одно или несколько полей; если ничего не выбрано, поиск идёт по всем полям. Доступна область «Создал» — поиск по автору записи.
  • Строка поиска — введите текст и нажмите «Применить».
  • Фильтры — выпадающие списки (тип структуры, тип объекта, метод сканирования и т.п.).
  • Быстрые фильтры — клик по цветной метке типа структуры, типа объекта, метода сканирования или по имени в колонке «Создал» подставляет условие в панель фильтров. В списке материалов также есть фильтр Источник импорта — материалы из конкретного загруженного файла.
  • Теги — клик по метке тега на карточке или в списке отфильтрует записи с этим тегом.
  • Активные фильтры — под панелью показываются чипы; крестик на чипе снимает одно условие, не сбрасывая остальные.
  • Сброс фильтров — ссылка появляется, когда заданы условия поиска или фильтрации.

На карточках просмотра (таблицы свойств, слоёв, сканов) — такая же панель с мгновенной фильтрацией строк без перезагрузки страницы.

Теги

Открыть раздел

Вкладки «Пространство» и «Общие»

Список тегов разделён так же, как материалы:

  • Пространство — теги текущего рабочего пространства. Их могут создавать менеджеры и операторы. Кнопка Выбрать позволяет группово удалить теги, которыми вы можете управлять.
  • Общие — глобальные теги для всех пространств. Создавать и редактировать их может только системный администратор.

В формах материалов, образцов и сканов доступны подсказки из обоих наборов: теги пространства и общие теги (блок «Доступные теги» под полем ввода; уже выбранные из списка скрываются). На списках клик по метке тега отфильтрует записи с этим тегом.

На карточке просмотра материала, образца или скана теги редактируются прямо на месте, если запись принадлежит активному пространству. У чужих (общих/ссылочных) записей теги только отображаются.

Цвет, описание и архив

  • Цвет — необязательный hex (#RRGGBB); метка отображается цветной, как в GitLab. Пустое поле — стандартный стиль.
  • Общие цветные теги — если у записи связан тег пространства без цвета, а есть одноимённый общий с цветом, в списках и на карточках показывается цвет общего.
  • Описание — подсказка при наведении на метку.
  • Архив — архивный тег остаётся на уже помеченных записях, но скрыт из выбора в формах. В списке тегов есть фильтр «Активные» / «Архив».

Область и значение (scoped)

Формат названия область::значение (один разделитель ::), например тип::баг. На одной записи не может быть двух тегов с одной областью — при выборе нового значения старое заменяется. Метка показывает область и значение отдельными частями.

При вводе нового тега система нормализует написание; похожие теги лучше не дублировать.

Практические рекомендации

  • Перед работой проверьте выбранное рабочее пространство в верхней панели.
  • Используйте единый формат кодов материалов и образцов — так проще искать и ссылаться друг на друга.
  • Сначала заполните справочник свойств (администратор), затем материал — так не придётся прерывать ввод.
  • При создании образца выбирайте материал на нужной вкладке: свои — в «Пространство», опубликованные чужие — в «Общие».
  • Для композитов с укладкой проверьте, что у типа структуры включены слои, и материалы слоёв уже заведены в базе.
  • Перед привязкой материала к типу структуры убедитесь, что для типа создана SQL-таблица — иначе форма не сохранится.
  • Имя SQL-таблицы лучше не менять в последний момент: задайте его при создании типа или проверьте на странице управления до нажатия «Создать».
  • Значения свойств вводите в тех единицах, которые указаны в справочнике (МПа, GPa, мм и т.д.).
  • Если форма не сохраняется — проверьте красные сообщения об ошибках и блок «Свойства»; возможно, не заполнено обязательное поле.
  • Расширенные настройки (группы свойств, пользователи, права) — в разделе Админка и в боковой панели для администраторов.
  • Суперпользователь может настроить резервное копирование БД в Администрирование → Бэкапы (автокопирование по расписанию с интервалом в днях, ручной дамп со скачиванием по ссылке, удаление файлов на сервере, восстановление из загруженного .dump или из файла на томе /backups). Файлы сканов и вложений в этот бэкап не входят.
