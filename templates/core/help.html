Справка по работе с базой

Эта страница описывает, как устроен сайт, в каком порядке вводить данные и на что обратить внимание. Разделы ниже соответствуют пунктам верхнего меню.

Общая схема данных

Данные связаны между собой так:

  1. Справочник свойств — названия и единицы измерения (плотность, модуль упругости и т.п.).
  2. Материал — карточка композита или заготовки с кодом, типом структуры и значениями свойств.
  3. Образец — конкретная деталь или пластина из материала; свойства можно уточнить для образца.
  4. Сканы и файлы — прикрепляются к образцу (ультразвуковые HDF5, фото, отчёты).

Рекомендуемый порядок: сначала завести нужные свойства в справочнике, затем материал, потом образцы и измерения.

Справочник свойств

Открыть раздел

Раздел Свойства в меню — это общий каталог параметров, которые потом выбираются в материалах и образцах.

  • Название — как свойство видно в интерфейсе (можно на русском).
  • Код свойства — заполняется автоматически из названия; при необходимости можно поправить вручную.
  • Единица измерения — необязательно (МПа, г/см³, % и т.д.).
  • Тип данных — число, строка, да/нет или дата.
  • Группа — для удобной группировки в списках (группы создаются в админке).

Один раз добавленное свойство можно использовать во многих материалах и образцах.

Материалы

Открыть раздел

Основные поля

  • Код — уникальный идентификатор (например, CMP-CFRP-T700-EP).
  • Название — понятное описание материала.
  • Тип структуры — определяет набор параметров конструкции (сэндвич, монолит и т.п.). После выбора типа появятся дополнительные поля; при смене типа страница перезагрузится.
  • Теги — необязательные метки для поиска (через запятую или выбор из подсказок).

Свойства материала

В блоке «Свойства» нажмите + Добавить свойство, выберите параметр из справочника и укажите значение. Строки можно удалять кнопкой ✖.

Слои композита

Если для выбранного типа структуры разрешены слои, появится таблица укладки: номер слоя, материал слоя, угол и толщина. Номера слоёв проставляются автоматически. На карточке материала отображается схема укладки и суммарная толщина.

Карточка материала

На странице просмотра — свойства, слои, параметры структуры, образцы, вложения. Отсюда же можно перейти к редактированию или создать образец из этого материала.

Типы структур

Открыть раздел

Тип структуры задаёт, какие дополнительные поля появятся у материала (толщина, тип обшивки, ссылка на другой материал и т.д.).

  • На странице типа можно просматривать и создавать записи структур этого вида.
  • Для нового типа нужно создать SQL-таблицу (кнопка в интерфейсе управления типом).
  • Флаг «Разрешить слои» включает таблицу слоёв композита в форме материала.

Настройка полей типа структуры — задача администратора базы; при сомнениях обратитесь к ответственному за систему.

Образцы

Открыть раздел

Образец — конкретная единица (пластина, деталь, контрольный элемент), изготовленная из материала.

Поля образца

  • Код и название — уникальный код и краткое описание.
  • Материал — обязательная связь с карточкой материала.
  • Тип объекта — испытательный, контрольный, изделие и др.

Свойства образца

При выборе материала свойства подставляются автоматически из его карточки. Значения можно изменить — они сохранятся только для этого образца.

Если добавить свойство, которого нет у материала, система покажет предупреждение (жёлтая подсказка в форме и сообщение после сохранения). Это не ошибка — образец может иметь дополнительные параметры.

Сканы HDF5 и произвольные файлы прикрепляются на вкладках «Сканы» и «Файлы» уже после создания образца.

Сканы и файлы

Все сканы

Сканы (HDF5)

  • Загружаются к конкретному образцу на вкладке «Сканы» или из общего списка сканов.
  • Принимаются только файлы .h5 и .hdf5 с корректной сигнатурой HDF5.
  • Указываются название, описание и метод контроля (эхо, теневой, зеркальный и др.).

Файлы-вложения

На вкладке «Файлы» образца можно прикрепить фото, PDF и другие документы с названием и описанием.

Поиск и фильтры

На страницах списков (материалы, образцы, сканы, свойства и др.) используется единая панель фильтров:

  • Где искать — отметьте одно или несколько полей; если ничего не выбрано, поиск идёт по всем полям.
  • Строка поиска — введите текст и нажмите «Применить».
  • Фильтры — выпадающие списки (тип структуры, тип объекта, метод сканирования и т.п.).
  • Сброс фильтров — ссылка появляется, когда заданы условия поиска или фильтрации.

На карточках просмотра (таблицы свойств, слоёв, сканов) — такая же панель с мгновенной фильтрацией строк без перезагрузки страницы.

Теги

Теги задаются в формах материала, образца и скана в поле «Теги» — через запятую или выбор из уже существующих. На списках тег отображается как метка; клик по ней отфильтрует записи с этим тегом.

При вводе нового тега система нормализует написание; похожие теги лучше не дублировать.

Практические рекомендации

  • Используйте единый формат кодов материалов и образцов — так проще искать и ссылаться друг на друга.
  • Сначала заполните справочник свойств, затем материал — так не придётся прерывать ввод.
  • Для композитов с укладкой проверьте, что у типа структуры включены слои, и материалы слоёв уже заведены в базе.
  • Значения свойств вводите в тех единицах, которые указаны в справочнике (МПа, GPa, мм и т.д.).
  • Если форма не сохраняется — проверьте красные сообщения об ошибках и блок «Свойства»; возможно, не заполнено обязательное поле.
  • Расширенные настройки (группы свойств, права доступа) — в разделе Админка.
