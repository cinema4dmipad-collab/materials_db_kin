# Changelog

Все заметные изменения проекта документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование — [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

### Added

- План и ADR: workspaces, RBAC (admin/manager/operator), GitLab-подобный sidebar ([docs/architecture/workspaces-rbac.md](docs/architecture/workspaces-rbac.md)).
- Приложение `apps.workspaces`: модели Workspace/Membership, middleware, login/logout, выбор пространства, sidebar, права manager/operator, UI администрирования пользователей и настроек WS.
- Зависимость `django-guardian`; команда `migrate_to_workspaces` для переноса prod-данных в Legacy WS.
- Форма материала: модальный выбор типа структуры; sticky-кнопки сохранения на длинных формах.
- Автоподстановка нового свойства в форму материала после создания из справочника.
- Образцы наследуют параметры структуры материала (просмотр и форма).
- Ссылки на материалы в пространстве (`WorkspaceMaterialLink`) вместо полного клонирования; кнопка «Добавить в пространство».
- Создание материала «на основе» общего: подстановка полей, свойств, слоёв и тегов (без образцов и файлов).

### Changed

- Material/StructureType/Sample/Scan: поля `home_workspace`/`workspace`, видимость и фильтрация по активному пространству; код уникален в пределах WS.
- Свойства: единица измерения в названии через запятую (колонка «Единица» сохранена).
- Точность десятичных полей структуры по умолчанию — 4 знака после запятой.
- Общие и ссылочные материалы: образцы и вложения показываются из домашнего пространства материала (readonly).

### Fixed

- Импорт `LocalizedFloatField` / `LocalizedDecimalField` в формах структуры.
- Синхронизация диаграммы слоёв композита при добавлении последнего слоя.
- Отображение свойств образца при смене материала через JSON API.
- 404 при открытии образца общего/legacy-материала (`home_workspace`/`workspace` = NULL).
- Предупреждение при создании материала с названием, совпадающим с уже опубликованным общим.

## [0.1.2] - 2026-06-17

### Added

- Debug: хэш git-коммита рядом с версией приложения.
- Форма материала: сводка ошибок валидации по разделам формы, свойств и слоёв.
- Django admin: ссылка на Debug в шапке для staff-пользователей.

### Changed

- Схема слоёв композита: высота диаграммы пропорциональна числу слоёв (максимум 320px).

### Fixed

- Горячие клавиши Del и Ins в таблице слоёв композита.
- Ложные ошибки уникальности при копировании слоёв (перенумерация до проверки формы).
- Валидация неполных строк слоя: понятные сообщения об обязательных полях.

## [0.1.1] - 2026-06-17

### Added

- Страница Debug: ссылки на админку S3 (Filer, Master, SeaweedFS Admin) и прокручиваемый список логов.
- Форма тегов: chip-интерфейс, фильтрация существующих тегов при вводе.

### Changed

- Список сканов: подсказка «добавляются через карточку образца» справа в заголовке.
- Справочник тегов: убрана колонка «Код» из интерфейса.
- Слои композита: компактный выбор материала без дублирующей кнопки «Выбрать».

### Fixed

- При выборе существующего тега в форме редактирования тег добавляется, а не заменяет предыдущий.

## [0.1.0] - 2026-06-17

### Added

- Модуль сканов и образцов с хранением файлов в S3 (SeaweedFS).
- Динамические таблицы структур материалов (SQL + админка Django).
- Связи материалов со слоями и структурными таблицами.
- Теги, фильтры и поиск в интерфейсе списков.
- FAQ-раздел.
- Логотип и обновлённая Bootstrap-вёрстка.
- Production Docker Compose для Dokploy (`docker-compose.prod.yml`).
- GitLab CI/CD: тесты, сборка образа, manual deploy staging/production.
- Compose для S3-хранилища (`docker-compose.storage.yml`).

### Changed

- Рефакторинг моделей структур: удалены legacy EAV-модели, улучшены формы.
- Упрощён prod compose под Dokploy (образы через `WEB_IMAGE` / `NGINX_IMAGE`, без build на сервере).
- Обновлены цвета и стили UI.

### Fixed

- Восстановлена установка зависимостей через Poetry в Dockerfile.
- Сборка web-образа из Dockerfile, когда `WEB_IMAGE` не задан.
- Пропуск docker build при redeploy в Dokploy.
- Подключение SeaweedFS к `dokploy-network` для доступа Django к S3.

### Security

- Безопасная конфигурация через переменные окружения (`SECRET_KEY` обязателен при `DEBUG=False`).
