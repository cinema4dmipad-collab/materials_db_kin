## Индекс дефектов

Формат — **таблица Markdown** (удобно сортировать и смотреть в Git / просмотрщике). Добавляйте строки; существующие не удаляйте без явной причины.

Колонки:

| Колонка | Содержимое |
| --- | --- |
| **Зафиксировано** | **Дата/время создания задачи в Jira** — поле **`created`** (`jira_get_issue` / REST), формат в таблице единый на весь цикл (например `YYYY-MM-DD HH:MM UTC` при ответе Jira в `+0000`). Не брать из имени файла черновика или локальных часов. |
| **Issue** | Ссылка на дефект в Jira вида `[LUS01-NNN](<JIRA_BASE_URL>/browse/LUS01-NNN)` или `—`, если задачи ещё нет. |
| **Кратко** | Короткая суть (одна строка); без вертикальной черты `|`, чтобы не ломать таблицу. |
| **Черновик** | Ссылка на `.md` черновик относительно `docs/tms/test_cycle/`: `[файл](defect-drafts/<имя>.md)`. Команда **`/create-defect-tms`** сохраняет черновики в `docs/tms/test_cycle/defect-drafts/`; запасной путь `~/.cursor/defect-drafts/...` — только если в репозиторий писать нельзя. |
| **Заметка** | По желанию: статус, «пустой черновик», дубль и т. п. |

Пример заголовка и одной строки-шаблона:

```markdown
| Зафиксировано | Issue | Кратко | Черновик | Заметка |
| --- | --- | --- | --- | --- |
| `<YYYY-MM-DD HH:MM>` | `[LUS01-NNN](<JIRA_BASE_URL>/browse/LUS01-NNN)` | `<кратко>` | [файл](defect-drafts/`<имя>.md`) | `<или пусто>` |
```

Плейсхолдер `<JIRA_BASE_URL>` возьмите из `docs/tms.project.yaml` → `jira.base_url` репозитория LUS.
