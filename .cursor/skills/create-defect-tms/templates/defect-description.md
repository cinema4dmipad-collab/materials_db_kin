# Дефект — шаблон (create-defect-tms)

- **Язык:** русский.
- **Jira `summary`:** одна строка (без markdown-заголовков).
- **Jira `description`:** блок **«Тело»** ниже — от `### Краткое описание` до `### Вложения и логи`, заголовки не менять.
- **Черновик файла:** оболочка из раздела «Черновик» + под `## Описание дефекта` вставить **тот же** блок «Тело» (без повторного придумывания формулировок).

## Черновик

Путь: `<workspace>/.cursor/defect-drafts/<YYYYMMDD-HHMM>-<slug>.md` или `~/.cursor/defect-drafts/...`

**Порядок секций в файле** (уровни заголовков сохранять):

1. `# Черновик: <summary>`
2. `## Статус` — `<черновик | ждёт | создано>` · Issue `<KEY|—>` · `<дата-время>`
3. `## Jira` — `<проект · тип · компоненты · priority · assignee · labels>`
4. `## Дубликаты` — `JQL...` · `<KEY — заметка>` · `<новый|связать|стоп>`
5. `## Описание дефекта` — сюда вставить **тот же** блок **«Тело»** целиком
6. `## Связи` — `<REQ/TC/…>` · `<link type, inward/outward>`
7. `## Подтверждение` — `<ждёт | да — цитата>`
