Создай возможность для композитных материалов ссылаться на другие материалы через структуру.

## Контекст
Композитный материал может состоять из нескольких слоёв или компонентов, каждый из которых является отдельным материалом. 
Например, сэндвич-панель: обшивка (материал А) + сердечник (материал Б).

## Что нужно сделать

### 1. В динамических таблицах структур
При создании/редактировании типа структуры (StructureField) добавить новый тип поля:
- Название: `MaterialLink` или `ForeignKeyMaterial`
- Суть: поле, которое ссылается на запись из таблицы `materials_material`

### 2. Генерация SQL
При создании динамической таблицы для такого поля генерировать:
```sql
field_name UUID REFERENCES materials_material(id) ON DELETE SET NULL
3. Интерфейс оператора
При заполнении экземпляра структуры (StructureInstance) для поля типа MaterialLink показывать:

Выпадающий список (select) с материалами

Отображать: code + name материала

Поле должно быть опциональным (можно не выбирать)

4. В админке
При добавлении поля в StructureField:

Добавить выбор типа MaterialLink в FIELD_TYPES

Убрать лишние параметры (max_length, max_digits и т.д.) для этого типа

5. Валидация
Проверять, что выбранный материал существует в БД

При удалении материала — обнулять ссылки (ON DELETE SET NULL)

Пример использования
Создаём тип структуры "Сэндвич-панель"

Добавляем поля:

skin_material (тип MaterialLink) → ссылка на материал обшивки

core_material (тип MaterialLink) → ссылка на материал сердечника

thickness (DecimalField) → толщина

Создаём экземпляр структуры:

skin_material: выбираем "Углепластик T700"

core_material: выбираем "ПВХ пена"

thickness: 25.5

Пользователь при создании материала выбирает эту структуру и заполняет ссылки на другие материалы

Ограничения
Только ссылка на Material (не на другие модели)

Без каскадного удаления (только SET NULL)

Реализуй это через расширение существующей системы динамических таблиц.

## Почему твой промт может не сработать:

| Твоя формулировка | Проблема | Исправление |
|------------------|----------|-------------|
| "ссылка на таблицу материалов" | Не указано, что это FOREIGN KEY | "поле внешнего ключа (UUID REFERENCES)" |
| "выбрать еще материал" | Непонятно, где выбирать | "при заполнении экземпляра структуры показывать select" |
| "будет возможность объявлять поля" | Не указано, кто объявляет | "администратор при создании типа структуры добавляет поле типа MaterialLink" |

## Дополнительные уточнения (добавь, если нужно):
